# Smart Campus Management System

## About the Project
The Smart Campus Management System is a web-based application designed to simplify and improve campus management through digital technology.

## Features
- Student management
- Campus information management
- Centralized data management
- User-friendly interface

## Technologies Used
- TypeScript
- React / Vite
- Node.js
- HTML and CSS

## Project Structure
- `data/` – Project data
- `server/` – Backend server files
- `src/` – Frontend source code
- `index.html` – Main HTML file
- `package.json` – Project dependencies and scripts

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/muppidimohankumar14/Smart-Campus-Management-System.git
   ```

2. Open the project folder:
   ```bash
   cd Smart-Campus-Management-System
   ```

3. Install dependencies:
   ```bash
   bun install
   ```

4. Start the development server using the script configured in `package.json`.
